Mis billeteras

Los saldos se leen directamente desde Supabase. CRX/Cerro aparece únicamente como moneda interna. No se muestra ningún precio de mercado para CRX.

TRANSFERIR

Transferir CRX

CRX es la moneda interna que sirve como puente para intercambios dentro de CUBA PLUS PAY. La transferencia se ejecuta mediante el RPC seguro del backend.

El backend calcula comisión, límites y cantidad neta. El navegador nunca modifica directamente un saldo.
MARKETPLACE

Marketplace

Espacio para comercios, productos y servicios reales. No se muestran productos ficticios ni precios inventados. CRX puede utilizarse como moneda interna de intercambio cuando el backend autorice la operación.
